# Кракозябра

**Progressive Web App (PWA)** з інструкцією з підготовки та виконання польоту безпілотного комплексу **«Кракозябра»** (дрон-ретранслятор + цільовий FPV).

## Особливості

- Чистий **HTML / CSS / JS** — без збірки, без залежностей, без бекенду
- **PWA** — встановлюється на домашній екран телефону / робочий стіл, працює офлайн після першого відкриття *(у розробці)*
- **Mobile-first** адаптивна верстка (телефон → планшет → десктоп)
- **4 теми оформлення** із перемиканням у хедері:
  - Світла
  - Темна
  - Matrix (чорний фон, ціанові акценти, моноширинний шрифт)
  - Win95 (класичний скевоморфний вигляд)
- На мобільному — бічне меню у вигляді **drawer** з гамбургер-кнопки
- На десктопі — фіксована бічна панель з навігацією
- **Збереження обраної теми** в `localStorage`
- Блоки `Увага!` та `Примітка` для акцентування ключової інформації

## Запуск

Достатньо відкрити `index.html` у будь-якому сучасному браузері — нічого встановлювати не потрібно.

```bash
# для повноцінної роботи PWA потрібен HTTP(S)-сервер:
python -m http.server 8000
# потім відкрити http://localhost:8000
```

> **Примітка.** Service Worker та встановлення як PWA не працюють при відкритті через `file://` — лише через `http://localhost` або HTTPS.
